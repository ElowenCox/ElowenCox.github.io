# Design System

## Creative direction

Blend:
- Engineering/executive precision
- Academic/scientific credibility
- Artistic/creative sophistication

The site should not look like a generic corporate template or a conventional academic CV.

## Visual language

Use subtle inspiration from:
- Water flow
- Infrastructure networks
- Microbial ecology
- Organic forms
- Engineering grids

Avoid cartoon bacteria, cliché DNA graphics, and generic stock-photo aesthetics.

## Typography

Use a modern sans-serif as the primary typeface. A restrained serif or editorial accent may be used for selected display text.

## Layout

- Generous whitespace
- Strong grid
- Clear hierarchy
- Short sections
- Data/metric callouts
- Editorial composition
- Responsive cards and timeline
- Minimal but intentional motion

## Color

Use a restrained palette that feels technical but not corporate. Favor deep neutral foundations with water-inspired accents and one warm/creative accent. Maintain WCAG-appropriate contrast.

## Motion

Use subtle entrance and hover transitions only.
Respect `prefers-reduced-motion`.

## Imagery

Prefer original/abstract visual treatments and meaningful photography over stock images.

## Responsive

Design intentionally for:
- desktop
- laptop
- tablet
- mobile

Navigation must remain obvious at every breakpoint.

# Elowen Cox — Professional Portfolio

GitHub Pages-ready professional portfolio for Elowen Cox, PE, PMP.

## Local development

This first version is a static site with no build step.

```bash
cd elowencox-portfolio
python3 -m http.server 8000
```

Then open http://localhost:8000.

You can also use the VS Code Live Server extension.

## Deployment

The site is designed for GitHub Pages. Copy the project contents into the repository used for the GitHub Pages site (for example `elowencox.github.io`) and enable GitHub Pages from the repository's main branch/root.

## Agent workflow

Read these files before making substantive changes:

- `agent/AGENTS.md`
- `agent/RUBRIC.md`
- `agent/CONTENT.md`
- `agent/DESIGN_SYSTEM.md`
- `agent/QA_CHECKLIST.md`

The agent must audit before changing the site and must never invent credentials, publications, research findings, teaching appointments, or personal facts.
